# ADR-0013: GitLab CI Collapsible Sections

## Status

Deprecated

## Context

CLI output in GitLab CI pipelines was hard to read without section grouping.

## Decision

Added GitLab CI collapsible section markers to CLI output. Deprecated as project moved to GitHub.

## Consequences

### Positive
- Better CI output readability in GitLab

### Negative
- GitLab-specific, not portable to GitHub Actions

## Date

2025-01-08
