# ADR-0006: Built-in Localization System

## Status

Deprecated

## Context

Initial plan included multi-language CLI output support.

## Decision

Implemented i18n system with locale files. Later deprecated in favor of English-only output to reduce complexity for open source release.

## Consequences

### Positive
- Was flexible for multi-language support

### Negative
- Added complexity without clear demand from target audience

## Date

2024-12-22
